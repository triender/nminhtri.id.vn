# nminhtri.id.vn

> Trang web cá nhân: [https://nminhtri.id.vn](https://nminhtri.id.vn)

Kho lưu trữ nội dung và bài viết cho trang web cá nhân.

---

## 1. Giới thiệu

Kho lưu trữ này dùng để sao lưu và quản lý nội dung các bài viết (định dạng Markdown) cùng tài nguyên hình ảnh đi kèm phục vụ trang web cá nhân.

---

## 2. Cấu trúc thư mục

- `content/vn/`: Các bài viết và siêu dữ liệu bằng tiếng Việt.
- `content/en/`: Các bài viết và siêu dữ liệu bằng tiếng Anh.
- `assets/images/posts/`: Các sơ đồ vector và hình ảnh minh họa đi kèm bài viết.

---

Nội dung các bài viết và hình ảnh trong kho lưu trữ này được chia sẻ theo giấy phép [Creative Commons Attribution 4.0 International (CC BY 4.0)](LICENSE).
