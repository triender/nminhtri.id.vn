# nminhtri.id.vn

> Trang web cá nhân: [https://nminhtri.id.vn](https://nminhtri.id.vn)

Kho lưu trữ cá nhân dùng để sao lưu và quản lý nội dung các bài viết kỹ thuật, ghi chép học tập và sơ đồ minh họa.

---

## 1. Giới thiệu

Đây là nơi lưu trữ nội dung dạng văn bản (Markdown) phục vụ trang web cá nhân. Các ghi chép chủ yếu xoay quanh các chủ đề:

- Thuật toán và cấu trúc dữ liệu.
- Kiến trúc hệ thống và công nghệ ảo hóa.
- Mô hình tư duy và logic phân tích.
- Tiêu chuẩn tiếp cận kỹ thuật số (WCAG).

Mục đích chính của kho lưu trữ là ghi chép có hệ thống để tiện tra cứu và ôn tập khi cần thiết.

---

## 2. Cấu trúc thư mục

- `content/vn/`: Các bài viết và siêu dữ liệu bằng tiếng Việt.
- `content/en/`: Các bài viết và siêu dữ liệu bằng tiếng Anh.
- `assets/images/posts/`: Các sơ đồ vector và hình ảnh minh họa đi kèm bài viết.
